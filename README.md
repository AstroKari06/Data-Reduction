# Data Reduction

University project focused on the reduction and preprocessing of astronomical observational data.

## Requirements

The following Python packages are required to run the code:

- [Astropy](https://www.astropy.org/)
- [NumPy](https://numpy.org/)
- [Matplotlib](https://matplotlib.org/)
- `pathlib` — included in the Python standard library, so no separate installation is required.

## Usage

After downloading or cloning the repository, configure the code to match your own observational data.

Before running the scripts, make sure to update:

- the **data directory** to the location of your files,
- the **input file names**,
- the **temperature** of the observations,
- the **exposure time**,
- the **master file names**, if necessary.

The parameters should be adjusted according to the data being processed.
